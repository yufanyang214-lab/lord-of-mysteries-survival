# 诡秘生存挑战

**你能在诡秘世界活到第几天？**

从廷根市的一条阴暗小巷醒来，经历二十次命运的岔路。每题四个选项，只有一条生路；答错后查看死亡回放，再向愚者祈祷一次奇迹。

**[▶ 在线游玩](https://yufanyang214-lab.github.io/lord-of-mysteries-survival/)**

在线入口在 GitHub Pages 首次部署完成后生效。

## 玩法

- 点击选项回答，也可用 Tab 选择、Enter 或空格确认。
- 死亡后点击“向愚者祈祷奇迹”，在当前题复活并重新排列选项。
- 答完全部 20 题即可通关，沿途可触发死亡成就与真神成就。
- 刷新页面会重新开始；题目含世界观剧透与娱乐性改编。

## GitHub Pages

在仓库 **Settings → Pages** 中选择：

- Source：**Deploy from a branch**
- Branch：**main**
- Folder：**/ (root)**

点击 **Save**，等待部署完成即可通过上方链接游玩。

游戏完整保存在 `index.html` 中，样式、题库和脚本均已内嵌，无需安装依赖或执行构建。仓库仅另保留本说明与 `.nojekyll` 发布标记。
